Archivo de pacientes

❓ ¿Cómo elegir la carpeta? (si le sale un error, lea aquí)
  1. Presione «Elegir carpeta de pacientes». Se abre una ventana de Windows.
  2. NO elija directamente «Escritorio», «Documentos», «Descargas» ni la raíz «C:». Windows no lo permite y aparece el error «contiene archivos del sistema».
  3. Entre a Documentos (o a su memoria USB), presione «Nueva carpeta» y llámela Archivo Pacientes.
  4. Entre a esa carpeta nueva, presione «Seleccionar carpeta» y luego «Ver archivos» / «Permitir»; si pregunta por modificar archivos, presione «Guardar cambios» / «Permitir».
  5. Use Google Chrome o Microsoft Edge. En Firefox o Internet Explorer no funciona.
  6. Si abrió el programa desde dentro del ZIP, primero descomprímalo (clic derecho › Extraer todo).

Agregar pacientes

Registre pacientes uno tras otro, de cualquier fecha o mes, aunque el informe lo haya hecho fuera del programa. Puede adjuntar el Word, PDF o imágenes. Después de guardar, la fecha y el estudio se mantienen para que agregue el siguiente rápido.

Importar varios informes anteriores

Seleccione varios Word o PDF a la vez, por ejemplo todos los de un mes. Los archivos con nombre tipo Nombre_Apellido_US_Estudio.docx se reconocen solos; para los demás, el programa le preguntará el nombre del paciente.
